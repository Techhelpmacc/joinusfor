# Experiments

One folder per idea. Copy `_template/` to start:

```powershell
Copy-Item -Recurse "..\_template" ".\my-idea"
```

**Naming:** after the *technique*, not the client — `brutalist-hero`,
`spa-warm-minimal`, `scroll-driven-story`. These are reusable lessons, not jobs.

**Rules of thumb**
- One technique per experiment. Mixing five ideas teaches you nothing about any of them.
- Fill in `NOTES.md` *before* writing code — the plan/critique passes are the point.
- Binning an experiment is a fine outcome. Write down why first.
- Check back here before starting a client site; you may have already solved it.
